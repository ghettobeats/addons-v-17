This module allows automating the allocation of the accounting account in the invoice lines for contacts (clients / suppliers) that are marked as internal services.

**Table of contents**

.. contents::
   :local:



Configure
=========

To configure this module, you need to:

#. Go to the contact and check the field "Internal Services" in the tab Accounting. When this field is checked a new field "Invoice Journal" is visible and required to select the journal that will be selected automatically in the invoices of this contact.
   .. image:: https://raw.githubusercontent.com/account_partner_internal_services/static/description/contact-internal-services.png

#. Go to the product categories and set the income account and expense account in the section "Internal Services".
   .. image:: https://raw.githubusercontent.com/account_partner_internal_services/static/description/product-category-internal-services.png
	






Usage
=====

To use this module, you need to:

#. Go to Accounting / Customers / Invoices, select a customer, if this contact is marked as "Internal Services" you will see as the journal will be selected automatically.

#. At the moment of add lines to the invoices the account will be automatically selected when you select the product, this account is pulled from the field "Income Account" of the product category.

#. This same behaviour applies for the vendor invoices.
