To use this module, you need to:

#. Go to Accounting / Customers / Invoices, select a customer, if this contact is marked as "Internal Services" you will see as the journal will be selected automatically.

#. At the moment of add lines to the invoices the account will be automatically selected when you select the product, this account is pulled from the field "Income Account" of the product category.

#. This same behaviour applies for the vendor invoices.
